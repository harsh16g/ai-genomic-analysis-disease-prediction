6. INTERPRETATION
------------------------------------------------------------
The experiment compares classical machine-learning methods using k-mer frequency features with a 1D convolutional neural network using one-hot encoded DNA sequences.

Random Forest achieved higher test accuracy than the CNN on this dataset. This suggests that the k-mer feature representation combined with a classical ensemble model is effective for this relatively small synthetic dataset.

The lower CNN performance should not be interpreted as evidence that CNNs are inferior for genomic sequence analysis in general. Deep-learning models typically benefit from larger datasets and more extensive training.

Note: The dataset used in this project is synthetic and relatively small. Therefore, the reported accuracies demonstrate the behavior of the implemented methods rather than real-world biological prediction performance.
